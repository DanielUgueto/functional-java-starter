# Functional Java exercises

Exercises for the Functional Java session: lambdas, functional interfaces, streams and Optional.

## Run it

Each lesson has its own class with a `main` method. Run it in IntelliJ with the green arrow next to `main`.

```bash
./mvnw test
```
All tests fail with `UnsupportedOperationException: TODO` until you solve the exercises. Run one test class at a time:

```bash
./mvnw test -Dtest=Lesson1LambdasTest
```
